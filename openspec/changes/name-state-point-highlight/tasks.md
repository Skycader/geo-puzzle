## 4. Правка после фидбека: границы между штатами тоже надо скрывать

- [x] 4.1 Пользователь указал: на Сложном/Хардкоре границы МЕЖДУ штатами
      оставались видимыми — по ним контур нужного штата легко
      проследить глазами, сложность была иллюзорной. Исправлено: класс
      `.name-hide-borders` на `<svg>` при `difficulty === "hard" ||
      "ultra"`, CSS `stroke: none` на `.quiz-path` внутри него — общая
      заливка у всех штатов делает соседние границы неразличимыми,
      виден только внешний контур страны. Обновлена спека (Requirement
      "Сложный уровень"/"Хардкор") — проверено вживую: на Хардкоре видно
      только внешнюю береговую линию США и точку, внутренних границ нет;
      на Среднем регрессии нет (границы и подсветка формы как раньше)
