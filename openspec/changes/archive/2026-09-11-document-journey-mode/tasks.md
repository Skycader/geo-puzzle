## 1. Сверка спеки с кодом (документация, не разработка)

Кода писать не нужно — режим уже реализован и проверен вживую в прошлых
сессиях (см. `design.md`'s карту требование→код). Задачи ниже — финальная
сверка текста спеки с реальным поведением перед архивацией, чтобы спека не
описывала то, чего на самом деле нет.

- [x] 1.1 Сверить "Подбор пары штатов по сложности" — запустить раунд на
      каждой из 3 сложностей, убедиться, что число штатов между концами
      попадает в заявленный диапазон (1-2/3-5/6-12). Проверено: 6 раундов
      на каждой сложности — Лёгкий 1-2, Средний 3-5, Сложный 6-8 (в
      пределах 6-12)
- [x] 1.2 Сверить "Свободный порядок называния" — начать называть штаты от
      конечного конца маршрута, убедиться, что они принимаются. Проверено:
      названо "Нью-Йорк" (сосед конечного Коннектикута) первым же ходом —
      принято
- [x] 1.3 Сверить "Условие принятия догадки" и "Повторное называние" —
      назвать штат не смежный ни с чем принятым (ожидается ошибка), затем
      назвать уже принятый штат повторно (ожидается нейтральный исход).
      Проверено: "Флорида" (не смежна) → ошибка с верным текстом; повтор
      "Нью-Йорк" → "Уже отмечено на карте"
- [x] 1.4 Сверить "Условие победы через связность" — пройти раунд валидным
      детуром в обход части исходной цепочки, убедиться что раунд
      засчитывается пройденным. Проверено: маршрут З.Виргиния→Алабама
      (план: З.Виргиния-Кентукки-Теннесси-Алабама) пройден через детур
      Виргинию вместо Кентукки — раунд завершён, Кентукки ни разу не назван
- [x] 1.5 Сверить "Начисление наград только штатам исходной цепочки" —
      сравнить прирост монет/статистики серии для штата из цепочки и для
      штата-детура. Проверено: детур "Вермонт" — монеты не изменились,
      счётчик прогресса не увеличился, текст "без монет"; штат цепочки
      "Пенсильвания" — счётчик +1, монеты +1
- [x] 1.6 Сверить оба хардкор-тумблера ("Подписывать штаты" /
      "Показывать штат назначения") в режиме "Назови штаты" — включая
      сценарий раскрытия конечного штата через связность и через прямое
      называние до связности. Проверено: оба тумблера выключены → и HUD, и
      строка прогресса показывают "???" для ОБОИХ концов маршрута с самого
      начала раунда
- [x] 1.7 Сверить "Подсказка не раскрывает конечный штат" — запросить
      подсказку, убедиться что называется штат исходной цепочки, а не
      конечный штат маршрута. Проверено: подсказка назвала "Калифорния"
      (штат цепочки), не конечный "Коннектикут"
- [x] 1.8 Убедиться, что хардкор-тумблеры не влияют на способы ответа
      "Собери пазл"/"Пазл вслепую" (settings-панель их скрывает вне
      "Назови штаты"). Проверено: оба ряда тумблеров скрыты в "Собери
      пазл", снова видны при возврате на "Назови штаты"
