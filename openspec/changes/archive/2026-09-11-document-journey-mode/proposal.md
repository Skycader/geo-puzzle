## Why

У режима "Путешествие" (`js/journeyNameBoard.js` + часть `_startJourney` в
`js/game.js`) накопилось несколько неочевидных правил (свободный порядок
называния, условие победы через BFS-связность, а не через строгий
`this.chain`, два независимых хардкор-тумблера с разной семантикой
"известности" штата), которые в этой сессии пришлось не раз заново
вычитывать из кода при каждой новой правке. Первая практическая проба
OpenSpec на этом проекте — задокументировать уже существующее, рабочее и
проверенное вживую поведение как базовую спеку, чтобы в следующий раз
свериться со спекой, а не перечитывать код заново.

Это НЕ новая фича и не изменение поведения — реализация уже написана и
проверена в предыдущих сессиях. Спека фиксирует то, что уже есть.

## What Changes

- Добавляется спека `journey-mode`, описывающая текущее поведение режима
  "Путешествие": свободный порядок называния штатов, условие принятия
  догадки, условие победы, начисление монет, три режима ответа
  (Назови/Собери пазл/Пазл вслепую), выбор сложности по числу штатов
  между, и два хардкор-тумблера ("Подписывать штаты" / "Показывать штат
  назначения") — только для режима ответа "Назови штаты".
- Код не меняется. Фаза `apply` (если до неё дойдёт) сведётся к сверке
  спеки с кодом, а не к правкам.

## Capabilities

### New Capabilities
- `journey-mode`: режим "Путешествие" — прокладка маршрута между двумя
  штатами через цепочку соседей, три способа ответа, регулируемая
  сложность, два хардкор-тумблера видимости названий.

### Modified Capabilities
(нет — это первая спека в проекте, изменять пока нечего)

## Impact

Затронутые файлы (только для справки, код не меняется): `js/journeyNameBoard.js`,
часть `js/game.js` (`_startJourney`, `_renderJourneyAnswerMode`,
`_renderJourneyDifficulty`, `_applyJourneyNameOptionsVisibility`),
`js/modes.js` (`JOURNEY_ANSWER_MODES`, `JOURNEY_DIFFICULTIES`), `js/i18n.js`
(`journeyProgressText` и связанные строки), `index.html` (панель настроек
Путешествия), `js/journeyRoute.js` (подбор пары штатов и цепочки —
используется, но не описывается этой спекой отдельно).
