## Context

См. `proposal.md` — новый режим для уровня "США: штаты". Ключевая находка
при исследовании кода: почти вся механика уже есть в двух существующих
board-классах, просто ни разу не скомбинирована вместе:
- `js/cityPinBoard.js` — расчёт расстояния до цели, живая красно-зелёная
  индикация, кнопка подтверждения, порог для награды, реализовано для
  ТОЧКИ (булавка города).
- `js/puzzleBoard.js` — перетаскивание настоящей SVG-фигуры штата,
  `hintsVisible`-переключатель (статичный пунктирный контур истинного
  положения — концептуальный предок направляющей стрелки).

## Goals / Non-Goals

**Goals:**
- Определить, какой код переиспользуется как есть, какой — по образцу
  (похожий приём, новый класс), а что — по-настоящему новое.
- Явно зафиксировать зоны допуска (проценты от эквивалентного радиуса
  штата, не выдуманные километры) и что происходит в каждом исходе.

**Non-Goals:**
- Не проектирует итоговый визуальный стиль стрелки/сердечек — только
  факт, что это новые SVG-ассеты в неоновом стиле проекта (см. уже
  существующие `MODE_ICON_SVG` в `js/game.js` как образец языка).
- Не решает вопрос наград (см. "Open Questions" ниже).

## Decisions

**Новый board-класс, не расширение существующих.** `CityPinBoard`
работает с точкой, `PuzzleBoard` — сразу со всеми штатами уровня;
ни один не подходит под "один случайный штат, который тащат целиком,
с трёх разной информативности отслеживанием" без искажения своей текущей
ответственности. Новый класс переиспользует ЛОГИКУ (не наследует
классы): формулу расстояния и цветовую интерполяцию из `CityPinBoard`,
механизм перетаскивания реальной фигуры — из `PuzzleBoard`.

**Зона допуска — относительная, не абсолютная.** Радиус эквивалентной
окружности `r = sqrt(area / π)` уже вычислим из существующего `area`
у каждого штата (реальное число, не выдумка). Пороги: лёгкий 50% `r`,
средний 20% `r`, сложный 8% `r`. Это даёт соразмерную сложность что для
Род-Айленда, что для Техаса — фиксированное число км было бы
несправедливым в любую сторону.

**Новый производный ассет — силуэт США без внутренних границ.**
Нужен билд-шаг: объединение (полигональный union/dissolve) 48
материковых штатов в один контур. В репозитории пока нет готового
инструмента для булевых операций над полигонами (mapshaper это умеет
через `-dissolve`, но раньше в проекте не применялось для этой цели) —
это НЕ тривиальное "просто перекрасить", а отдельный, самый рискованный
с технической стороны шаг всей задачи.

**Только 48 материковых штатов.** Аляска/Гавайи используют true-position/
инсет-проекции с уже нестандартным масштабом и локатором — тащить их
"на своё место" в этой механике добавило бы отдельный, непропорционально
сложный частный случай. Решение пользователя, зафиксировано в
`proposal.md`.

**Не сбрасывать позицию после неудачной попытки (Средний/Сложный).**
Игрок поправляет положение и жмёт "Проверить" заново — так теряет смысл
только число попыток, а не наработанная интуиция о направлении.

## Risks / Trade-offs

- [Риск] Полигональное объединение 48 штатов может дать неточный/дырявый
  контур на стыках (упрощение границ, не идеально стыкующееся между
  соседними штатами) → Смягчение: визуально проверить готовый силуэт
  перед использованием, при необходимости — лёгкое сглаживание.
- [Риск] Относительный порог допуска (% от радиуса) может ощущаться
  слишком щедрым для очень маленьких штатов (Род-Айленд, Делавэр) при
  крупном масштабе экрана → Смягчение: проценты — начальная гипотеза,
  можно перекалибровать после первого живого теста, не меняя саму формулу.
- [Риск] Реализация тянет на несколько существенных кусков работы
  (новый билд-ассет + новый board-класс + новые SVG-ассеты + интеграция
  в меню/настройки) — заметно больше типичной правки в этом проекте →
  Смягчение: `tasks.md` разбивает это на независимо проверяемые шаги.

## Open Questions

- **Награда/монеты**: давать ли одинаковую награду на всех трёх
  сложностях, или больше — за более сложный уровень (как это принято в
  некоторых других режимах, например пресетах паззла)? Не решено —
  безопасно отложить: не меняет спеку/подход/разбивку задач, только
  число в конфиге на этапе реализации.
