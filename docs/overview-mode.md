# Режим «Обзор» (`js/overviewBoard.js`)

Самая большая и самая часто развиваемая часть проекта (~3,1 тыс. строк в одном
классе `OverviewBoard`). Свободный просмотр карты без заданий: слои, список
объектов справа, карточки с Википедией, линейка. Работает на любом уровне;
набор слоёв зависит от данных уровня (`level.cities`, `places`, `lakes`,
`highways`, `airports`, `currents`).

## Что видит игрок

**Вкладки правой панели** (`_buildSidePanel`; в названии — счётчик `(N)`):

| Уровень | Вкладки |
|---|---|
| США | Штаты, Города, Места, Водоёмы, Шоссе, Аэропорты |
| Моря и океаны | Океаны, Моря, Остальное, Течения (классификация по названию: `_pieceCategory` — «океан»→океаны, «мор»→моря, остальное — прочее) |
| Страны мира | Страны, Города, Места (города и места мира — только здесь) |

Панель: поиск с крестиком, сортировка (по названию; по площади там, где она есть),
клик по строке — перелёт и подсветка (`_focus*`, жёлтый контур 3 с,
`FOCUS_DURATION_MS`). Панель шириной 340 px, сворачивается кнопкой-язычком.

**Слои** — меню «Слои» в шапке (`#settings-flyout-menu`, открывается по hover):

| Тумблер | Условие показа | Метод доски |
|---|---|---|
| Города (id `toggle-hints`, переиспользован) | есть `level.cities` | `setCitiesVisible` |
| Подписи | всегда | `setLabelsVisible` |
| Места | есть `places` | `setPlacesVisible` |
| Водоёмы | есть `lakes` | `setLakesVisible` |
| Шоссе | есть `highways` | `setHighwaysVisible` |
| Аэропорты | есть `airports` | `setAirportsVisible` |
| Течения | есть `currents` | `setCurrentsVisible` |
| Прогресс | только США; цвет штата по серии верных ответов | `setProgressVisible` |
| Рельеф | только США; 3 положения: выкл / цвет / иконки | `setTerrainMode` (динамический импорт `usaTerrain.js`) |

У каждого слоя с внешними данными справа иконка «источник» (`.source-btn`): раскрывает
под строкой заметку с источником, лицензией и ссылкой на официальный сайт
(`js/dataSources.js`; показ по уровню — `Game._showSourceButtons`).

Выбор «Отображение» в меню: **Полная информация** — все слои включены;
**Скрытая информация** — все выключены (названия видны по наведению через
нативный `<title>`). «Прогресс» всегда стартует выключенным.

Прочее: правый клик — линейка (точки, расстояние/периметр/площадь) и меню с
координатами, «Открыть в Google Maps», «Скопировать координаты»; выбор подложки
(`_buildLayerSwitcher`): **SVG** (офлайн), **OpenStreetMap** (iframe), **Топо**
(тайлы Tracestrack); у Канады (США) — подпись и правый клик → карточка.

## Устройство

**Порядок слоёв SVG** (снизу вверх; проверено по DOM):
`zones-layer` (фигуры территорий, фон-страны, озёра, силуэты городов) →
`currents-layer` → `labels-layer` (все названия) → `points-layer` (города, места,
аэропорты) → `highways-layer` → `ruler-layer`. Подписи вынесены в отдельный слой,
чтобы ничто не перекрывало названия.

**Размеры в пикселях экрана.** Значки, подписи, обводки пересчитываются при каждом
зуме в `_rescaleForZoom(zoom)` (`effScale = scale × zoom`). Подписи территорий
показываются только при зуме ≥ `LABEL_MIN_ZOOM` (3) — костыль против «каши» на
общем плане (`SPACE_VIEW_LABEL_HIDE_ENABLED`). Стрелка течения и значки
аэропортов зависят от зума (см. ниже).

**Виртуализация городов.** В DOM лежат только города в видимой области
(`_updateVisibleCities`, по `onVisibleRectChange` с задержкой ~150 мс); показ
порциями по 6 за кадр (`_queueReveals` / `_processRevealQueue`). Места, аэропорты,
шоссе, течения не виртуализированы — всегда в DOM.

**Клик по объекту.** `_onMapTap` берёт ближайший элемент с `data-kind`/`data-id`
(`closest('[data-kind]')` — значки аэропортов составные); виды: `city`, `place`,
`lake`, `contextland`, `airport`, `current`, `state` (при включённом «Прогрессе»).
Информация лежит в `this.info.<kind>[id]` (`{extract, image, wikiUrl}`),
загружается один раз (`loadInfo()`). Объект с карточкой получает класс
`overview-has-info` (курсор-«рука»; у аэропортов и течений — курсор-вопросик).
Карточка (`_openInfoPopup`): картинка закреплена, текст прокручивается;
положение — внутри видимой области (`_visibleBounds()` — пересечение карты,
окна и открытой правой панели); закрывается при панорамировании/зуме.

**Подсветка** (`_focusShape`): зум к bbox + копия контура поверх всего
(`.overview-focus-glow`); для линий (шоссе, течения, ВПП) добавляется класс
`overview-focus-glow-line` (обводка без заливки).

## Особенности слоёв

**Шоссе.** Данные — `level.highways`: США (`number`, щиты `I-NN`) + Гавайи (имя,
без номера). Список: сначала нумерованные по возрастанию номера, потом гавайские по
алфавиту; поиск по `I-5`/`5`/`i5`. Щит каждого шоссе показывается в точке,
ближайшей к центру вида (`_updateHighwayShields`).

**Аэропорты (144).** Файл `levels/usaAirports.js`: точка `cx,cy`, настоящие ВПП
в `d` (по концам из OurAirports), `runwayCount`, `longestM`, флаг `minor`.
Значок — группа `<g.overview-airport-plane>`: самолёт (22 px, основные, 58 шт.)
или вертолёт (17 px, `minor`, 86 шт.); у основных подпись-код IATA всегда, у
`minor` — только при зуме ≥ 4. ВПП — линии синим `#2f9bff`, постоянной толщины
(`vector-effect: non-scaling-stroke`). Подсказки: «Национальный аэропорт — связывает
страну и мир, дальние рейсы» / «Региональный аэропорт — связывает регионы и
штаты». **Это наше упрощённое деление**, не роль FAA: по таблице FAA за 2025 год
в «основных» все 30 large hubs + 20 medium + 3 small + 2 nonhub + 3 без данных
(мелкие гавайские), а в «региональных» оказались 14 medium hubs (JAX, ONT, SNA, BOI,
OMA и др.), 50 small и 22 nonhub. Исправление «по хабам FAA» предложено, но не
сделано. Код Палм-Бич в данных OurAirports сейчас `DJT` (в FAA — тоже `DJT`).

**Течения.** `levels/worldCurrents.js`: ломаная `pts` (путь по реальному полю
скоростей OSCAR), `d` для подсветки и зоны клика, `temp` (`warm` красный /
`cold` синий), `mid` — якорь подписи. Стрелка: линия обрывается у основания
наконечника, тот строится на лету по хорде основание→кончик (`_layoutCurrent`),
размеры растут с зумом от тонкого (1 px линия / 2,5 px наконечник) к полному
(4 / 7 px) к зуму 4 (`CURRENT_*` в начале файла). Сейчас в данных одно течение —
Гольфстрим (путь от ~31°с.ш., 79°з.д. до ~38°с.ш., 50°з.д.; дальше усреднённое поле
закручивается, поэтому линия обрезана в самой восточной точке).

**Города мира (только countries).** `levels/worldCities.js`: ~247 городов (200 столиц по
Natural Earth + города от ~4 млн). Нет площади → вместо `radiusKm` у записи `pop`; `OverviewBoard`
рисует такие города постоянным кружком (`WORLD_CITY_DOT_PX`), в списке колонка «Население»
(заголовок меняется на «Площадь» на вкладках с площадью), подпись города скрыта на малых зумах
(`cityMinLabelZoom`: ≥5 млн — всегда, ≥1,5 млн — с зума 2, остальные — с 3,5; столицы не позже 2,5).
Карточки — `levels/world/cities-info.json` (уровень countries) вместо `usa/cities-info.json`.
Источник слоя в меню «Слои» подменяется на «Natural Earth» (`_showSourceButtons(keys, remap)`).

**Страны на «Моря и океаны».** Фоновые страны (`level.land`) подписаны названиями (подписи
берутся у одноимённых стран уровня countries, см. `levels/index.js`; для Антарктиды и Израиля — центр
фигуры) и показывают название при наведении (`<title>`); мелкие территории и спорные зоны только с
подсказкой. Подпись крупной страны видна уже на общем плане, мелкой — при приближении
(`countryLabelMinZoom` по площади, порог в `stateLabels[].minZoom`).

**Рельеф и «Прогресс»** — только США; рельеф берёт `levels/usaTerrain.js`
(экорегионы CEC в 9 категориях).

## Как добавить новый слой (рецепт, как делались аэропорты и течения)

1. **Данные:** скрипт `scripts/build_*.js` → `levels/<имя>.js` (с шапкой
   «Auto-generated … Regenerate») + при необходимости info-JSON
   (`{id: {extract, image, wikiUrl}}`); зарегистрировать поле в `levels/index.js`.
2. **Доска (`overviewBoard.js`):** константы размера; массив записей
   `xEntries` и `xById` в конструкторе; цикл построения в `_build()` (выбрать слой
   SVG: фигуры — `zonesLayer`, линии-поверх — отдельный слой, названия — **всегда**
   `labelsLayer`); пересчёт размеров в `_rescaleForZoom`; `setXVisible()` и
   вызов в `_build()` рядом с остальными `set*Visible`.
3. **Клики и карточка:** `data-kind`/`data-id` на элементе; ветки в `loadInfo`,
   `this.info`, `_applyInfoAvailability`, `_onMapTap`, `_openInfoPopup`.
4. **Вкладка:** `_tabCount`, кнопка в `_buildSidePanel`, ветка в `_renderList`
   (элементы, `showArea`, сортировка), обработчик клика → `_focusX` (через
   `_focusShape`), при необходимости ветка в `_mainColumnHtml`.
5. **Тумблер слоя:** `<label class="toggle" id="toggle-x-wrap" hidden>` +
   `.source-btn` в `index.html`; `this.el.toggleX*` и `change`-обработчик в
   `game.js`; **`toggleXWrap.hidden = true` во всех `_start*`** (грепни
   `toggleAirportsWrap`); выставление видимости/чекбокса и ключ в
   `_showSourceButtons([...])` в `_startOverview`; передать `xVisible` в
   конструктор доски.
6. **Тексты:** `js/i18n.js` (подпись вкладки, тумблера, подсказки, RU+EN);
   `js/dataSources.js` (источник, лицензия, ссылки — проверить, что открываются).
7. **CSS** в `style.css` (без скруглений; цвета — не от переменных схемы, если
   значок должен оставаться одним цветом в обеих схемах).
8. **Проверка:** `node --check`, запустить игру, пройти вкладку/тумблер/клик/
   карточку, смотреть консоль; для линий — разные зумы.
