## 4-я вкладка в Обзоре: ПОРТЫ (аэропорты + морские порты)

Запрошено: добавить 4-ю вкладку в side panel режима "Обзор" (сейчас там
Штаты/Города/Места) — категория "Порты", покрывающая официальные
аэропорты и морские порты. Для теста — сначала только Гавайи.

### Решённые вопросы дизайна

- **Иконки**: аэропорты и порты — РАЗНЫЕ иконки на карте (не один общий
  стиль маркера). По аналогии с уже существующей парой в коде: щит шоссе
  (`_buildHighwayShield`) / подпись гавайского шоссе (`_buildHighwayLabel`)
  — тот же паттерн "два вида маркера внутри одной категории данных".
- **Тумблер видимости**: нужен отдельный переключатель "показать/скрыть
  порты" в настройках, как у `toggle-places`/`placesVisible`.

### Архитектура — копирование существующего паттерна "Места"

Вкладка "Места" уже спроектирована с расчётом на расширение (см.
комментарии в overviewBoard.js: "Everything else... just gets a plain
name"). Ничего нового изобретать не нужно — методичное дублирование в
следующих местах:

- **`js/overviewBoard.js`**:
  - `_buildSidePanel` — 4-я кнопка вкладки `data-tab="ports"`
  - `_renderList` — источник данных `this.level.ports`, `showArea` тоже
    `false` для портов (как у мест)
  - Рендер-цикл маркеров — копия цикла для `places`, только с двумя
    вариантами иконки (аэропорт/порт) вместо одной точки
  - `setPortsVisible`, `_portHoverTitle`, `_focusPort` — копии
    одноимённых методов для places/cities
  - `loadInfo()` (строки ~265-280) — сейчас жёстко грузит 2 JSON
    (cities-info.json, places-info.json), нужен 3-й (ports-info.json);
    `this.info = { cities: {}, places: {} }` (строка ~375) → добавить
    `ports: {}`
  - `_onMapTap`/клик-инфо-попап (строки ~966, ~981) — switch по `kind`
    сейчас `'city'`/`'place'`, нужна ветка `'port'`
- **`levels/index.js`** — добавить поле `ports: [...]` в уровень USA (и
  пустые массивы `ports: []` в world/countries, как уже сделано для
  `places`)
- **Новый `scripts/build_usa_ports.js`** (копия `build_usa_places.js`) →
  `levels/usaPorts.js` + `levels/usa/ports-info.json`
- **`index.html`** — новый `<label class="toggle" id="toggle-ports-wrap">`
  по образцу `toggle-places-wrap`
- **`js/game.js`** — правка по аналогии с `togglePlaces`/`placesVisible`
  (обработчик чекбокса + проброс в `PortsVisible`/board)
- **CSS** — 2 новых SVG-глифа (иконка самолёта, иконка якоря/порта)

Риск архитектурно низкий — это не новый дизайн, а повтор уже рабочего
паттерна в ~10 точках кода.

### Данные — реальные официальные объекты, Гавайи для теста

- **Аэропорты**: сеть Hawaii DOT Airports Division, ~15 штук (включая
  совсем маленькие грунтовые полосы вроде Калаупапы или Дилинхэма).
- **Морские порты**: сеть Hawaii DOT Harbors Division, ~10 коммерческих
  гаваней.
- Итого ~25 объектов. Каждому нужны реальные координаты (Wikipedia/
  официальные источники, тот же стандарт, что уже используется для
  городов/мест) + вики-статья на русском, где есть — иначе перевод с
  английской с честной пометкой и ссылкой на реальную статью (как уже
  делалось для части гавайских городов/мест без RU-статьи).
