записи копятся здесь; в `RELEASES` / `APP_VERSION` версия ещё не поднимается.

## Добавлено

- **«Номера штатов»:** чеклист штатов (по номеру вступления в Союз) — можно выбрать, какие номера практиковать; поиск по названию и по номеру; выбор запоминается отдельно от других режимов.
- Адаптация меню под узкие экраны (телефон / планшет): вместо трёх колонок сразу — вкладки **Уровень / Режим / Настройки** на всю ширину панели, затем **Играть**. На широком экране по-прежнему три колонки рядом.
- Режим **«На время»** для раундовых режимов (найди/назови/сосед/определи/моря/города/раскраска/расположи штат/метка): переключатель «На время» ↔ «Количество»; 60 секунд, лимит 3 ошибки; сколько успеешь.

## Изменено

- Кнопка справки «Номера штатов» (i): квадратная рамка и SVG вместо круглого italic «i», в стиле остальных контролов.
